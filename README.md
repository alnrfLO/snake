# 🐍 Snake

Le jeu **Snake** classique en Python avec **Pygame**.

## Fonctionnalités

- Le serpent grandit à chaque fois qu'il mange de la nourriture
- Score affiché en direct
- Écran de défaite avec la possibilité de rejouer

## Contrôles

| Touche | Action |
|---|---|
| `← ↑ → ↓` | Diriger le serpent |
| `C` | Rejouer (après une défaite) |
| `Q` | Quitter (après une défaite) |

## Installation

```bash
pip install pygame
python snake.py
```

## Technologies

- Python 3
- Pygame
